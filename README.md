# Groq LLM Python Project

A simple Python project that connects to the Groq API and sends a prompt to an LLM. The program takes a prompt, sends it to the selected model, and prints the generated response.

## What this project does

- Connects to the Groq API
- Uses the `openai/gpt-oss-120b` model
- Sends user prompts to the LLM
- Supports an optional system prompt
- Allows the temperature to be adjusted
- Displays the generated response in the terminal

## Technologies Used

- Python
- Groq API
- Groq Python Library

## Requirements

- Python 3.x
- A Groq API key
- Internet connection
